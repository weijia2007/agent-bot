## 2. 本轮修复与补全的关键缺陷

1. **SQLite FTS5 真实索引落盘与检索链路**
   - 新增 [RelayFtsIndex.cs](file:///C:/Users/17839/Desktop/NexusBotStudio/engine/native/RelayFtsIndex.cs)，调用系统 `winsqlite3.dll` 建立 `<RelayHome>/v1/search-fts5.db`；在 `RelayBox.Post()` 写入同时增量建索引，并支持对既有历史 `.json` 消息懒同步、重音折叠及中文字符 bigram/unigram 命中；向 `/api/search` 暴露。
2. **多 Bot 路由与回复广播缺陷**
   - 修复 `McpServer.ToolSend` 对任意 review 请求无差别扩散到旧 `claude/antigravity/codex` 邮箱的问题：现仅当发送方与目标均为传统三端时才自动扩散。
   - 放宽 `McpServer.ToolWaitReply` 最多 3 条 ID 限制至 24 条。
   - 修复 `McpServer.ToolReply` 此前缺失 `BotEvents.Publish("message_posted", ...)` 及 `trace_id` / `hop_count` / `max_hops_reached` 传递的问题，使 Bot 间互答和最终回执都能实时显示在群聊流并触发唤醒/跳数熔断。
   - 修复 `Orchestrator` 唤醒同房 Bot 时仅传裸文本的问题，现携带 `message_id`、`from`、`room/topic`、`trace_id`、`hop_count` 及明确 `reply(id=..., as_bot=...)` 提示。
3. **EditGuard 文件锁双向同步与真实释放**
   - `McpServer.CallToolPayload` 为 `reserve` / `release` / `file_reservation_paths` / `release_file_reservations` 补充完整参数并推送 `locks_changed`。
   - `BotControl` 新增 `GET /api/locks` 与 `DELETE /api/locks/<id>`（支持 `"user"` 强制接管释放），`Orchestrator.releaseLock` 调用引擎 API 完成真实释放并刷新状态。
4. **Electron 主进程 → 界面 WebSocket 实时推送**
   - 新增 [ws.ts](file:///C:/Users/17839/Desktop/NexusBotStudio/desktop/electron/ws.ts) 实现带 token 校验、心跳与大帧（>64KB）处理的 RFC 6455 WebSocket 服务端；在 [main.ts](file:///C:/Users/17839/Desktop/NexusBotStudio/desktop/electron/main.ts)、[preload.ts](file:///C:/Users/17839/Desktop/NexusBotStudio/desktop/electron/preload.ts)、[store.ts](file:///C:/Users/17839/Desktop/NexusBotStudio/desktop/src/store.ts) 与 CSP 中打通，WS 就绪后实时事件走 WebSocket 通道推送。
5. **Engine 保活与 Git Worktree Diff 完整性**
   - `EngineBridge` 增加 `NexusRelay.exe` 意外退出的自动拉起与重注册恢复逻辑。
   - `worktree.ts` 的 `collectDiffs` 改用分支 `merge-base` + `git ls-files --others` 计算 diff 并提供完整 `Unified Patch` 与 `Side-by-side` 视图，`removeWorktree` 补充 `git worktree prune`。
6. **跨重启会话连续性、多房间主管隔离与运行时热配置**
   - **三引擎跨重启会话延续**：修复 [claude.ts](file:///C:/Users/17839/Desktop/NexusBotStudio/desktop/electron/adapters/claude.ts)、[codex.ts](file:///C:/Users/17839/Desktop/NexusBotStudio/desktop/electron/adapters/codex.ts)、[antigravity.ts](file:///C:/Users/17839/Desktop/NexusBotStudio/desktop/electron/adapters/antigravity.ts) 在桌面端重启后丢失 `external_session_id` 的问题；Claude 对“建 Bot 后尚未发起首轮即重启”的场景自动回退一次 `--session-id`；Codex 修复已有 `threadId` 二次触发 `thread/start` 与 `outputdelta` 大小写漏匹配 bug；Antigravity 追踪在途 `agentapi` 子进程以支持真实紧急停止中止。
